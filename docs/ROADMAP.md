# ROADMAP

`MASTER_PLAN.md` §5를 실행 가능한 형태로 옮기고, 리뷰에서 빠진 것으로 확인된 태스크를 **[추가]** 로 끼워 넣었다.
원래 번호는 유지하고, 추가분은 `1.1a` 같은 접미사를 쓴다.

**규칙**
- 태스크 하나 = 작업 단위 하나. 완료 기준을 실제로 만족시킨 뒤 다음으로.
- 완료하면 여기 체크박스와 아래 "현재 위치"를 갱신한다.
- Phase 완료 조건을 만족하기 전에 다음 Phase로 넘어가지 않는다.
- 사이트는 Phase 7까지 접근 게이트 뒤에 있다.

## 현재 위치

**Phase 0 완료. Phase 1 진행 중.**

- 구조 리뷰 9개 항목 확정 → `DECISIONS.md` D-01~D-09 (`1.0a` 완료)
- Phase 0 실행 중 결정 5건 → `DECISIONS.md` D-10~D-14
- 앱이 basic auth 뒤에서 Vercel에 떠 있고, CI가 typecheck·lint·test·시크릿검사를 돌린다
- Supabase 로컬 스택 기동 중 (스키마는 아직 없음)

**Phase 1 전 태스크 완료.** 테스트 100 + 라이브 12.

```

  01:00 PT 스케줄 등록                                   basic auth 뒤
```
